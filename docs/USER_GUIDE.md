# Camp-Bot — Руководство пользователя по ролям
**Версия:** 2026-06-04

> Бот доступен в Telegram. Мини-приложение открывается кнопкой «📱 Открыть приложение» в главном меню.
> Все команды начинаются с `/`. Кнопки меню кликабельны — отправлять текст вручную не нужно.

---

## АДМИНИСТРАТОР (admin)

### Доступно всё. Главное меню:
`👥 Сотрудники` | `🏕 Отряды` | `✅ Задачи` | `📅 Расписание` | `👦 Дети` | `📱 Открыть приложение`

---

### Управление сотрудниками

| Действие | Как сделать |
|----------|-------------|
| Добавить сотрудника | `👥 Сотрудники` → `➕ Добавить` → ввести Telegram ID → ФИО → выбрать роль. Бот автоматически отправит приветствие новому сотруднику. |
| Список сотрудников | `👥 Сотрудники` → `📋 Список` → листать страницы ◀️▶️ |
| Изменить роль | `👥 Сотрудники` → выбрать сотрудника → `✏️ Роль` → выбрать новую |
| Деактивировать | `👥 Сотрудники` → выбрать сотрудника → `❌ Деактивировать` → подтвердить |
| Рассылка всем | `/broadcast` → ввести текст → подтвердить |

---

### Управление задачами

| Действие | Как сделать |
|----------|-------------|
| Создать задачу | `✅ Задачи` → `➕ Создать задачу` → название → группа → исполнитель (или «Всей группе») → приоритет → дедлайн (опционально) |
| Прикрепить фото к задаче | После создания задачи нажать `📷 Фото` → отправить фотографию |
| Все задачи | `✅ Задачи` → `📋 Все задачи` → листать страницы |
| Просроченные | `✅ Задачи` → `⚠️ Просроченные` |
| Создать шаблон | `✅ Задачи` → `📝 Шаблоны` → `➕ Новый шаблон` → заполнить поля |
| Создать из шаблона | `✅ Задачи` → `📝 Шаблоны` → выбрать шаблон → `▶️ Создать задачу` |
| Поставить на паузу | В задаче нажать `⏸ Пауза` → ввести кол-во дней |
| Удалить задачу | В задаче нажать `🗑 Удалить` → подтвердить |

> При создании задачи на группу — все члены группы получат уведомление.
> При установке дедлайна — исполнитель получит напоминание за 1 час.

---

### Управление сменами и расписанием

| Действие | Как сделать |
|----------|-------------|
| Создать смену | `/sessions` → `➕ Создать смену` → название → дата начала → дата конца |
| Активировать смену | В списке смен выбрать → `✅ Активировать` |
| Добавить пункт расписания | `/schedule_add` → тип дня → время → название |
| Скопировать расписание | `/copy_schedule` |
| Сгенерировать дежурства | `/generate_duties` → период → типы |

---

### Управление мероприятиями (Календарь)

| Действие | Как сделать |
|----------|-------------|
| Создать мероприятие | `📅 Расписание` → `➕ Мероприятие` → название → тип → место → ответственный → участники → начало → конец |
| Мероприятия сегодня | `/events_today` |
| Мероприятия на неделю | `/events_week` |
| Редактировать | `/events_week` → выбрать → `✏️ Редактировать` |
| Скопировать | В мероприятии → `📋 Копировать` → ввести новую дату |
| Удалить | В мероприятии → `🗑 Удалить` → подтвердить |

> После создания мероприятия участники автоматически получат напоминания: за 24ч, за 3ч, за 30 мин.

## СТАРШИЙ ВОЖАТЫЙ (senior_counselor)

Доступно то же, что у администратора, кроме создания и деактивации сотрудников.

**Отличия от администратора:**
- Нельзя добавлять/деактивировать сотрудников
- Нельзя генерировать отчёты Excel
- При медицинском инциденте — получает уведомление

Все остальные функции идентичны разделу «Администратор» выше.

## ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

**Q: Я нажал «Мой отряд», но ничего не происходит.**
A: Убедитесь, что ваш профиль привязан к отряду. Обратитесь к администратору.

**Q: Я не получаю уведомления от бота.**
A: Бот должен не быть заблокирован в Telegram. Отправьте /start для переподключения.

**Q: Как поменять свой отряд?**
A: Самостоятельно нельзя. Обратитесь к администратору — он изменит через управление.

**Q: Импорт Excel не работает.**
A: Файл должен быть в формате `.xlsx` или `.xls`. Обязательна колонка с ФИО. Сначала выберите отряд (1–14), затем отправьте файл.

**Q: Мини-апп не открывается / показывает ошибку авторизации.**
A: Убедитесь, что открываете через Telegram (не в браузере). Ваш Telegram ID должен быть зарегистрирован администратором.

**Q: Задача исчезла из «Мои задачи».**
A: Задачи со статусом «Выполнена» не показываются в списке активных. Они хранятся в журнале.
